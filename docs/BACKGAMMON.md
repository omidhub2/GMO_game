# تخته‌نرد محلی GMO ARENA

## اجرا

در ریشهٔ همین پروژه در PowerShell:

```powershell
npm.cmd run dev -- --hostname 127.0.0.1
```

سپس `http://127.0.0.1:3000/games/backgammon` را باز کنید. وابستگی‌ها در پروژه موجودند؛ برای نصب تازه `npm.cmd ci` لازم است.

## قابلیت‌ها

- بازی دو نفره روی یک دستگاه با رابط فارسی، بدون انتخاب یا جابه‌جایی خودکار مهره‌ها.
- حفظ مختصات و چیدمان تخته؛ شماره‌ها از دید بازیکن فعال محاسبه می‌شوند و RTL جهت حرکت را تغییر نمی‌دهد.
- تاس شروع برای دو بازیکن، تکرار تساوی و استفاده از همان تاس‌های شروع؛ تولید تصادفی با Web Crypto و حذف سوگیری تقسیم.
- موتور مستقل از React در `src/modules/games/domain/backgammon.ts`؛ بررسی تمام ترتیب‌های تاس با حافظهٔ نتایج وضعیت‌های تکراری، الزام بیشترین تعداد حرکت و تقدم تاس بزرگ‌تر در حالت تک‌حرکت.
- انتخاب دستی مبدأ و یک مقصد برای هر تاس، نمایش تمام گزینه‌های مجاز همراه عدد تاس، علامت زدن و دکمه‌های خروج برای هر عدد قانونی. در خروجی که با چند تاس مجاز است، خود بازیکن عدد مصرفی را انتخاب می‌کند.
- اولویت ورود تمام مهره‌های Bar، زدن، ادامهٔ همان مهره پس از زدن، خروج دقیق و خروج با تاس بزرگ‌تر از بالاترین خانهٔ اشغال‌شده.
- چهار واحد مصرف مستقل برای جفت؛ انتقال خودکار و یک‌بارهٔ نوبت پس از آخرین حرکت ممکن.
- برگشت با تصویر کامل وضعیت پیش از هر حرکت؛ شامل مهره‌های مبدأ/مقصد، Bar، خروج و تاس‌ها. پس از پایان نوبت یا خروج پانزدهمین مهره، سابقه پاک و برگشت بسته می‌شود.
- فرمان‌ها شمارهٔ نسخهٔ وضعیت دارند؛ فرمان تکراری یا قدیمی پذیرفته نمی‌شود. قفل هم‌زمان رابط نیز کلیک‌های هنگام انیمیشن را مسدود می‌کند. نتیجهٔ تاس پیش از انیمیشن ثبت می‌شود.
- برد عادی، مارس، بک‌گمون؛ حالت ساده بدون مکعب و مسابقه‌های ۱، ۳، ۵، ۷، ۹ و ۱۱ امتیازی با مالکیت مکعب، پذیرش/رد، ضرب امتیاز و Crawford برای دقیقاً یک دست.
- کنترل با دکمه‌های استاندارد قابل‌استفاده با صفحه‌کلید، لغو انتخاب با Escape یا فضای خالی، پیام زنده، برچسب‌های غیررنگی و کاهش حرکت مطابق تنظیم سیستم.

مبنای قوانین حرکت و امتیاز: [آموزش رسمی USBGF](https://usbgf.org/backgammon-basics-how-to-play/). قواعد مکعب و Crawford با [قوانین مسابقات USBGF](https://usbgf.org/tournament-rules/rules-for-in-person-play/) تطبیق داده شده‌اند. محدودیت برگشت تا پیش از پایان خودکار نوبت، تصمیم طراحی صریح این پروژه است.

## بررسی

```powershell
npm.cmd test -- src/modules/games/domain/backgammon.test.ts src/components/backgammon-game.test.ts
npm.cmd run typecheck
npm.cmd run lint
```

۳۳ آزمون موتور و ۶ آزمون تعامل DOM موفق‌اند. پوشش شامل جفت با صفر تا چهار حرکت، ترتیب اجباری تاس‌ها، برگشت تا مرز نوبت، بازیابی زدن و خروج، ورود چند مهره، تقارن دو بازیکن، کلیک تکراری و ثابت‌ماندن ۱۵ مهره در چند بازی کامل با دنبالهٔ تصادفی تکرارپذیر است. صفحهٔ محلی با HTTP 200 پاسخ می‌دهد؛ نمایش تاس و انتخاب مقصد در پیش‌نمایش واقعی نیز بررسی شد.

آزمون‌های قدیمی `tests/homepage.test.ts` هنوز متن داشبورد قبلی را مستقیماً در `src/app/page.tsx` جست‌وجو می‌کنند؛ صفحهٔ اصلی فعلی فقط `game-menu` را صادر می‌کند. این سه شکست به تغییرات تخته‌نرد مربوط نیستند و در این کار تغییر داده نشده‌اند.

## محدودیت‌های فعلی

- این نسخه محلی و دونفره روی یک دستگاه است؛ اتاق آنلاین، همگام‌سازی بین دستگاه‌ها، احراز هویت دو بازیکن و تأیید سمت سرور پیاده‌سازی نشده‌اند. موتور مستقل برای استفادهٔ مجدد در سرور آماده است، اما اعتماد به وضعیت یا تاس کلاینت برای بازی آنلاین مجاز نیست.
- وضعیت بازی در حافظهٔ صفحه است؛ بازخوانی صفحه بازی را از ابتدا شروع می‌کند.
- هوش مصنوعی حریف و ذخیرهٔ تاریخچهٔ مسابقات ارائه نشده‌اند.
- CSS واکنش‌گراست و گزینه‌های مقصد دکمه‌های جداگانه دارند؛ بررسی بصری روی گوشی واقعی انجام نشده است.
